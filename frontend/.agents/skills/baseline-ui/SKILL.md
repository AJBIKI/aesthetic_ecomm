# Baseline UI Skill

## Audit Checklist
- Every container uses exact spacing tokens (`--spacing-1` through `--spacing-32`).
- Font scales use fluid `clamp()` values.
- Interactive states (hover, focus, active, disabled) are explicitly defined.
- Contrast ratios meet WCAG AA standards in OKLCH color space.
