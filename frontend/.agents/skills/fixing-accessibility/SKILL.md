# Fixing Accessibility Skill

## Audit Checklist
- Minimum 44×44px touch targets on all buttons and interactive triggers.
- `:focus-visible` ring defined with custom Deep Teal outline.
- All non-text content has descriptive `alt` tags or `aria-hidden="true"`.
- Keyboard navigation works across modals, drawers, and size selectors.
